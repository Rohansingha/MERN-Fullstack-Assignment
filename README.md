# MERN-Fullstack-Assignment

🧠 About This Project – SmartBridge MERN Full Stack Assignment
Welcome to my weekly assignment submission for the SmartBridge MERN Full Stack Internship!
This project is a part of the learning journey under the MERN (MongoDB, Express.js, React.js, Node.js) stack development program. Each week, I'm building and enhancing real-world applications using the full MERN stack, following industry best practices and integrating core concepts of modern web development.

🛠️ What You’ll Find Here
Frontend: Built using React.js, it includes responsive layouts, reusable components, routing (React Router), and dynamic UI rendering.
Backend: Created using Node.js with Express.js, handling RESTful APIs, middleware logic, and server-side routing.
Database: Integrated with MongoDB to store and manage data efficiently using Mongoose ODM.
Functionality: Each week's assignment introduces new features like authentication, CRUD operations, form handling, state management, API integration, and more.
